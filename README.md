# NXEditYCDXML

Windows x64 desktop editor for previewing and replacing GTA V CodeWalker YCD XML animation clips.

Download the latest installer from [Releases](https://github.com/xnatta/NXEditYCDXML-Releases/releases/latest).

Features: rigged ped preview, Original/Source/Result views, clip replacement, rename/delete/timing, undo/redo, local projects/recovery, Thai/English interface, and manual online updates.

Game models, textures, sample XML, projects, and application source are not distributed in this repository. Import your own rigged ped XML. Vehicle import and bone pose editing are outside version 0.1. XML-to-YCD binary conversion is a separate CodeWalker step.

Installer is unsigned. Published installers include SHA-256 sidecars; the updater verifies SHA-512 and size. Node.js and .NET are not required on the destination computer.
